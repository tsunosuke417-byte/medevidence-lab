# 2分デモ台本

## 0:00–0:20 — 課題

「MedEvidence Labは、医学的な問いをPubMedの根拠から調べる学習支援アプリです。結論だけでなく、どの文献に基づくかを必ず確認できるようにしました。」

## 0:20–0:55 — 正常系

質問例「高血圧に対する減塩の効果は？」を選び、検索を実行する。生成された検索式、要約、注意点、文献カード、PMIDリンクを順に示す。

## 0:55–1:20 — 検証可能性

「これは診療推奨を生成しているのではなく、抄録中の結論候補を抽出しています。発表年・著者・PMIDを残し、必ずPubMedの原文へ戻れる設計です。」

## 1:20–1:45 — 回答拒否

「私は胸が痛い。何の病気？」を入力し、個別診断や緊急相談には回答しないことを示す。

## 1:45–2:00 — 締め

「医学知識をコードだけでなく、安全要件、評価項目、失敗時の振る舞いへ変換した点がこの作品の中心です。」
