# MedEvidence Lab — Portfolio one-pager

## Profile

医学部で得た医療知識を、検証可能なAIプロダクト開発につなげたいと考えています。公開医学情報を根拠付きで探索するアプリを設計・実装し、出典表示、回答拒否、評価データ作成まで行いました。

## Problem

医学情報を検索すると、結論だけが切り取られ、出典・対象集団・限界を追えないことがあります。生成AIを使う場合、この問題はさらに大きくなります。

## Solution

日本語の問いをPubMed検索式へ変換し、NCBI APIから抄録を取得。回答より先にPMID・原文リンクを示し、抄録から結論候補を抽出します。個別診断、緊急相談、根拠なしの質問には回答しません。

## What I built

- Next.js / TypeScriptによるレスポンシブWebアプリ
- PubMed ESearch・EFetch連携
- XML解析、出典付きレスポンス、外部API失敗処理
- 安全ゲートと回答拒否
- 単体テスト、20問の評価セット、日英ドキュメント

## What I learned

AI機能の価値は、回答の流暢さだけでなく、失敗時の振る舞い、出典の追跡可能性、利用範囲の明示で決まります。医学知識を仕様・評価基準・安全設計に変換する経験を得ました。
